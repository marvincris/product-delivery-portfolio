# Product Delivery Portfolio

This repository contains **no proprietary code**. It is a clean-room portfolio focused on product thinking, delivery methodology, and architecture decisions.

## Who I Am
I am a product delivery leader and systems architect who ships pragmatic software, balances tradeoffs, and documents decisions clearly.

## What I Build
I build operational products that turn messy workflows into reliable systems—typically in retail operations, scheduling, and small-business tooling.

## How I Work
- Start with the problem and target users.
- Define success metrics and constraints.
- Design architecture that favors clarity and iteration.
- Use AI for acceleration, with human accountability for decisions.
- Document tradeoffs so future work stays aligned.
